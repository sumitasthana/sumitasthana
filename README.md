## Hi, I'm Sumit

AI and machine learning engineer in Pittsburgh. Fifteen years of shipping
production systems, most of it in regulated industries where a wrong answer
has consequences.

### How I got here

I started out learning how enterprise systems actually work, which mostly
meant reading other people's domain logic. Then years of building predictive
models and worrying about them quietly drifting once they were live. After that,
pulling signal out of unstructured data. Then real-time fraud detection and
knowledge graphs, which is where the metadata and lineage work started. Now it
is multi-agent LLM systems, pointed at compliance problems.

### What I do now

By day: multi-agent orchestration on AWS Bedrock with Neo4j, built for
regulatory compliance. A lot of this is getting systems to read the code
instead of the documentation, so they can say where a number came from, what
touched it on the way, and what will break when something upstream changes.
In a large organisation nobody actually knows this. It sits in hundreds of
scripts, and the docs stopped being true years ago.

By night: in-context learning theory, how memorization spreads across
transformer layers, and model compression. I write about it, and I build small
free things that teach AI concepts to people starting out.

One thing I keep insisting on: a proven answer and a model's best guess should
never look the same to whoever reads the output.

### What I usually reach for

Python, LangChain and LangGraph, Neo4j, AWS Bedrock, FastAPI, React, Docker.
